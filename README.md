# Практическая работа 6 — ООП

Выполнил: Цапков Н. В., группа 09с41.

Программа разделена на три модуля:
- `people.py` — базовый класс Person, Student, Teacher и исключение AnketaError;
- `registry.py` — загрузка анкет, статистика, сохранение;
- `main.py` — запуск программы и вывод таблицы.

В файле `anketa.txt` находятся записи: `тип;ФИО;почта;телефон;группа/кафедра`.
Символ `s` обозначает студента, `t` — преподавателя.

```bash
python main.py
python -m pytest -q
```

Папка `Разминка` содержит пять отдельных упражнений по ООП.
